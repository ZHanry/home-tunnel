# nestlink 13.0.0

13.0.0 为正式版发行目标，统一英文品牌 nestlink、桥形图标与蓝白工作台。所有界面隐藏可见滚动条，保留滚轮、触控、键盘和无障碍滚动。

## 平台与使用

| 平台 | 架构与产物 | 用途 |
| --- | --- | --- |
| Web | Server 部署包与 amd64/arm64 镜像 | 管理账号、设备和穿透服务；在浏览器内直接远控 |
| Windows | x64 GUI 安装器 | 远控、被远控、内网穿透中枢 |
| Linux | x64 / ARM64 GUI DEB | 远控、被远控、内网穿透中枢 |
| Android | ARM64 / x86_64 通用 APK | 设备与服务管理、远控 |

客户端启动后登录自建 HTTPS 服务，自动获取连接配置。Web 在同一服务下按设备 ID 发起远控；被控端必须批准或验证远控密码。原生客户端保留 Rust/Flutter 远控核心，浏览器使用受控的直接 WebRTC 数据通道传送画面与输入；服务端只处理认证、授权与信令，不转发远控画面。无法建立安全直连时结束连接。

Windows/Linux 在“内网穿透”内配置并运行 HTTP/HTTPS、受控 TCP/UDP 服务，保留端口池、访问控制、流量治理和诊断。远控与穿透独立启停。客户端后台运行通过桌面和托盘入口管理；不再分发独立 CLI/NAS 产品，也不开发或发布 macOS GUI。

## 认证与升级

账号密码登录、自动续期和可撤销设备登录取代旧入口。事务迁移清除 MFA、恢复秘密和设备接入码，使旧管理会话失效；保留设备身份、有效后台凭据和穿透配置。认证与原生许可继续使用冻结的 api-v2.0.0，浏览器远控新增独立版本契约。原穿透协议的必要兼容接口保留。

Windows 使用 DPAPI，Linux 使用 Secret Service，Android 使用 Keystore。Android applicationId、原发行证书与既有 Windows/Linux 安装升级身份保持兼容。Windows 安装器尚无 Authenticode 发布者签名。

## 发行与验证

发布前必须通过当前提交的自动构建、安全检查、安装升级、浏览器与实际原生两端联调。当前 13.0.0 正在实施和验证，尚未发布，下载清单不提前登记文件或摘要。最终说明和材料记录实际执行过的范围及尚缺的真机、运营商网络和长期媒体检查。

各组件发行包含实际构建字节、SHA-256、对应源码、许可证及构建证据。Client 五个附件为 Windows 安装器、两种 Linux DEB、材料 ZIP、SHA256SUMS；Android 三个，Server 三个，分发仓两个。生产部署升级另行执行。历史标签和发行材料可在 GitHub 历史版本中查阅，当前站点和文档仅展示 13.0 的新界面。
