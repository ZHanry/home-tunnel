# nestlink 13.0.0

13.0.0 为正式版发行目标，统一英文品牌 nestlink、桥形图标与蓝白工作台。所有界面隐藏可见滚动条，保留滚轮、触控、键盘和无障碍滚动。

## 平台与使用

| 平台 | 架构与产物 | 用途 |
| --- | --- | --- |
| Web | Server 部署包与 amd64/arm64 镜像 | 管理账号、设备和穿透服务；在浏览器内直接远控 |
| Windows | x64 GUI 安装器 | 远控、被远控、内网穿透中枢 |
| Linux | x64 / ARM64 GUI DEB | 远控、被远控、内网穿透中枢 |
| Android | ARM64 / x86_64 通用 APK | 设备与服务管理、远控 |

客户端启动后登录自建 HTTPS 服务，自动获取连接配置。Web 在同一服务下按设备 ID 发起远控；被控端必须批准或验证远控密码。原生客户端保留 Rust/Flutter 远控核心，浏览器使用受控的直接 WebRTC 数据通道传送画面与输入；服务端只处理认证、授权与信令，不转发远控画面。无法建立安全直连时结束连接。

Windows/Linux 在“内网穿透”内配置并运行 HTTP/HTTPS、受控 TCP/UDP 服务，保留端口池、访问控制、流量治理和诊断。远控与穿透独立启停。客户端后台运行通过桌面和托盘入口管理；不再分发独立 CLI/NAS 产品，也不开发或发布 macOS GUI。


实际测试和能力边界以最终构建材料记录为准。
