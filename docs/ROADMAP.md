# 开发路线

项目处于内部测试。以下是工作方向，不构成发布日期或已完成能力的承诺。

## 当前重点

- 验证源码构建、服务端配置生成和首次登录流程。
- 完善 GUI、CLI 和 Android 的错误反馈、重试与状态一致性。
- 扩大 Windows、macOS、Linux 和 Android 的真实设备验证。
- 检查断网重连、设备撤销、权限隔离和备份恢复。
- 让文档示例与实际命令、产物和接口保持一致。

## 对外测试前

- 为每个平台确定可安装、可校验的测试包和分发方式。
- 明确协议变更、版本标识及测试环境重建方式。
- 根据真实测试结果整理平台范围和已知问题。

## 正式发布前

- 确定稳定版本标准、支持范围和更新流程。
- 完成签名、产物来源验证、部署与恢复演练。
- 根据测试记录决定哪些能力可以作出稳定性与兼容性承诺。
