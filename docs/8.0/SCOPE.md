# 8.0 已确认范围与开发工作表

本文件将项目方案 2.0 与此次确认的扩展合并为 8.0 开发范围。状态是开发中；稳定版仍为 7.0.0。方案中将多窗口列为 8.1、音频/剪贴板/文件/增强编码列为 8.2 的安排已被本次范围覆盖，不再作为延期依据。

| 能力 | 8.0 交付要求 | 当前状态 |
| --- | --- | --- |
| 控制面 | 独立身份、双端配对、本机授权、DPoP、ES256、持久租约、撤销、四出站/单入站配额 | 已实现，自动化验证中 |
| 共享协议 | API 1.2、独立 RD/ABI 版本、四语言常量与真实签名向量 | 已生成，尚未冻结发行标签 |
| 原生媒体 | 同源 C++20/libwebrtc；实际 UDP 对确认后才开放数据 | 锁定 Windows 引擎已编译；本机真实捕获/编码/UDP/解码通过，产品互通待验证 |
| Windows | 捕获、编码、解码、输入、隔离 worker、权限与单包升级 | 安全核心、原生签名验证及输入适配已有构建测试；worker 集成待完成 |

| 运维 | STUN-only、限流、迁移校验、密钥轮换、备份恢复与 epoch | 实现及自动化验证中；公网隔离部署待验证 |
| 发布 | 四独立仓库、PR、质量检查、RC 产物/报告/摘要，保留 7.0 稳定入口 | 尚未发布 8.0 候选版 |

所有画面、声音、输入、剪贴板和文件必须经 UDP P2P。UDP 无法直连时明确失败，禁止 TURN、ICE-TCP、FRP、HTTP 或 WSS 载荷回退。NAS/CLI 保持独立，不因无图形能力而报告可被控。

Windows 产品虚拟麦克风必须使用产品驱动及合法发行签名；macOS 使用 AudioServerPlugIn 和发行身份；Linux 使用 PipeWire 虚拟输入。测试替身、静音轨和编译成功均不能作为这些功能已可用的证据。

范围不含 Android 被控、登录前/UAC 安全桌面、跨账号共享、图片剪贴板、目录递归传输。现有用户数据与部署环境不用于破坏性验收。

完整门禁见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，逐项结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。

2026-09-23 开发检查点：浏览器 32 项界面回归、22 项远控协议测试及桌面 13 项界面回归通过。原生本机证据见 [windows-native-probe.json](evidence/windows-native-probe.json)。它没有替代 Windows/浏览器产品互通、跨网或任何平台完整验收。
