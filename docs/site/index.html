适用边界

为家庭服务设计，不是通用代理。

Home Tunnel 集中管理身份、配置与审计，Web 路径另有访问和流量策略；客户端能力始终限制在管理员签发的范围内。

适合

  • 远程访问 NAS 与家庭相册
  • 安全发布 Home Assistant
  • RTSP-over-TCP 与固定端口 UDP
  • 需要用户、设备与带宽管理

不适合

  • 完全匿名的公共代理服务
  • raw IP、ICMP、广播或组播
  • 无需认证的敏感管理后台
  • STCP、XTCP、SUDP、visitor 或任意插件

默认安全边界

  • 短期租约和即时策略撤销
  • 能力受限的固定 FRP Agent
  • 独立控制与业务流量路径
  • 连接配置与操作审计

FAQ

部署前最常见的问题。

它与直接使用 FRP 有什么不同？

Home Tunnel 在 FRP 之上增加用户、设备、连接、短期租约、访问控制、限速、采样与审计，并限制 Agent 只能执行控制中心签发的配置。

如何穿透 RTSP 或 RTP/RTCP？

RTSP 不是独立类型：将公网 10554/TCP 映射到摄像头本地 554，并使用 ffplay -rtsp_transport tcp rtsp://PUBLIC_HOST:10554/path。原生 RTP/RTCP UDP 必须固定媒体端口并逐条映射；动态端口不保证可用。

可以公开访问我的真实控制台吗？

不建议把管理控制台作为公开演示站。Pages 仅展示本地夹具生成的静态截图，不连接任何真实部署。

Windows 客户端怎么安装？

按客户端构建指南生成完整测试包，其中包含 GUI 和受管 Agent。内部测试阶段主要使用源码构建路径。

会收集家庭服务地址或凭据吗？

不会。Pages 只接收聚合访问与点击事件；部署反馈也明确禁止提交域名、IP、令牌或凭据。
