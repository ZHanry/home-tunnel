开始之前，你可能想知道。

需要自己的服务器和域名吗？

需要。公网 Linux 主机运行控制台和转发，家中的电脑或 NAS 主动连接它。家中设备不需要公网 IP。

Android 会在手机上运行隧道吗？

Android 负责远程管理；隧道持续运行在家中的客户端主机上。

能否混用 6.x 和 7.0 客户端？

支持组合为四个组件和自有 Agent 7.0.0。新的分页与安全流程需要同步升级；FRP 保持独立版本。
