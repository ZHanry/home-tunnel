开始之前，你可能想知道。

需要自己的服务器和域名吗？

需要。公网 Linux 主机运行管理与隧道服务，家庭设备主动连接。远程桌面另走两端 UDP 直连，服务器不转发远控画面、输入或文件；UDP 不可达时明确失败。

Android 会在手机上运行隧道吗？

隧道运行在家中的电脑或 NAS。Android 保留远程管理，并接入控制端；真机解码和输入尚未验收。

从 7.0 升级需要注意什么？

升级前先备份并结束远控会话，参阅组件升级说明。8.0 保留原有隧道兼容路径；旧服务端不提供新的远控能力。完整升级与恢复验收仍有待验项目，7.0 历史下载继续保留。
