远控走 UDP，服务发布走 FRP。

用自己的服务器连接家里的电脑和服务。远程桌面在授权后只走两端 UDP 直连；NAS、Home Assistant 和其他本地服务通过 FRP 发布。当前可以下载的稳定版是 9.0.0。10.0.0 正在开发，验收尚未完成，没有稳定安装包。

远程控制控制其他设备在 Windows、Web 或 Android 上选择设备。画面和输入只走 UDP，连不上就停，不改走 FRP。 远程控制允许控制本机只在 Windows 被控端上操作。这个网站不能把本机开放给别人。 内网穿透发布家里的服务用 FRP 发布 HTTP/HTTPS、TCP 和 UDP。电脑或 NAS 运行隧道。

已发布的 9.0.0 远控

双方登录同一台服务器，再建立直连。

用设备码找到设备。授权方式是本机批准、固定密码或一次性密码。固定密码和一次性密码都不是账号密码，设备码也不是接入码。服务器负责身份、授权和信令；画面和输入不经过 FRP。

  • Windows、Web 和 Android 可以控制其他设备。允许控制本机只出现在 Windows 被控端。
  • Linux x64 X11 只提供观看、键盘和鼠标，证据来自隔离环境。Android 的模拟器结果不能代替已发布的 arm64 APK。
  • 无法建立 UDP 直连时会失败。没有 TURN、ICE-TCP、FRP、HTTP 或 WSS 载荷回退。

仅 Windows 被控端

允许控制本机

本机批准、固定密码、一次性密码，以及计划中的无人值守，都在被控的 Windows 电脑上设置。设备码用来识别那台电脑。一次性接入码只用来把电脑登记到服务器，不能当作远控密码。

FRP 0.70.1

发布本地服务时，走原来的隧道。

家庭电脑或 NAS 上的 Agent 连接你的 FRP 服务。HTTP/HTTPS 经过你自己的边缘和网关；TCP/UDP 使用管理员分配的端口，不附带 HTTP 登录保护。目标应用自己负责认证和加密。

  1. 部署 9.0.0 服务端，改掉初始管理员密码，并打开 MFA。
  2. 在家里的电脑或 NAS 安装同版客户端，用账号或一次性接入码登记设备。
  3. 先确认本机能打开目标服务，再创建连接，然后从另一张网络访问公网地址。

10.0.0 计划的步骤是：设备与模板、本地目标、访问方式、验证与地址。模板只填入可编辑的初始值，不表示服务已经通。公网 TCP/UDP 端口由服务器分配。向导验收尚未完成。

常见问题

远控和内网穿透有什么区别？

远控是授权后的 UDP 直连，用来看画面和操作键鼠。内网穿透用 FRP 把家里的 HTTP、TCP 或 UDP 服务发布出去。两条路径不互相代替。

必须自己有服务器吗？

要。公网 Linux 主机运行控制面和 FRP。家庭设备主动连上去。这个项目网站不提供公共演示服务器。

UDP 连不上会自动改走隧道吗？

不会。远控载荷没有中继回退。失败时界面应给出可操作的直连错误，而不是悄悄改用 FRP。

可以下载 10.0.0 吗？

不可以。10.0.0 还在开发，验收尚未完成，没有稳定包。请继续使用 9.0.0。

安全桌面、音频和文件已经可用吗？

还没有验收结果，不能当成 10.0 已支持的能力。9.0 的已知限制见范围页。

Windows 安装包有发行签名吗？

没有。Windows 和 macOS 没有 Authenticode 或 Developer ID 发行证书。请核对 SHA-256。Android 继续使用原来的发行证书。
