开始之前

需要自己的服务器吗？

需要。部署 Web 服务端后，各客户端登录这个服务。信令与连接配置由服务端下发。

浏览器能直接操作电脑吗？

可以。选择 Windows 或 Linux 设备，或输入设备 ID；对方批准或验证远控密码后，在浏览器内操作。

P2P 直连失败会怎样？

连接会明确结束并显示错误。远控不使用媒体中继；FRP 穿透按自己的生命周期运行。

Android 要下载哪个包？

只有一个通用 APK，包含 ARM64 与 x86_64。保留原应用 ID 和发行证书，支持原安装升级。
