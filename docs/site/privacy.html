隐私

隐私说明

项目网站

此网站提供产品说明和下载链接，不要求登录，不收集 Home Tunnel 账号或设备凭据。网站托管在 GitHub Pages，访问时由托管服务处理基础请求信息。主题选择保存在这台浏览器的 localStorage 里，键名是 home-tunnel-theme，不会发到服务器。

仓库里的访问统计默认是空的。只有在 GitHub Pages 生产主机配置了 GoatCounter 的 HTTPS /count 地址时，页面才会从 gc.zgo.at 加载计数脚本。计数只针对这个网站的访问，不包含 Home Tunnel 账号、远控画面或隧道凭据。GoatCounter 的说明见 goatcounter.com/privacy。

自托管服务

账号、设备、连接、流量统计和审计记录存储在你部署的服务器上，由部署管理员管理。设备凭据用于连接授权。Android 登录用于管理你自己的服务器，不在这个项目网站上保存。

远控的画面、输入、文件和声音不经过本网站。自托管服务器负责身份、授权和信令；加密 UDP 优先在两端之间直连，浏览器控制端也可以经你自己服务器上的可选 TURN 中继，中继读不到内容。FRP 发布的是你配置的本地服务，流量经过你自己的服务器，而不是这个文档站。

反馈与联系

通过 GitHub 提交问题时，请去掉密码、令牌、私钥、接入码和个人信息。安全问题使用 私密漏洞报告，不要发到公开 Issue。仓库里的 SECURITY.md 有同样的入口。
