Privacy

隐私说明

此页面是项目信息站，不连接任何真实 Home Tunnel 控制台，也不提供可操作的公开演示。

统计内容

当仓库变量配置了公开 GoatCounter 端点时，Pages 会记录聚合页面访问、来源和以下命名点击事件：Quick Start、Release、GitHub 与部署反馈。网站不设置分析 Cookie，也不向 GoatCounter 发送家庭服务域名、IP、账号、凭据或部署配置。

统计端点

端点由仓库所有者创建并通过 GitHub Actions 变量注入。若变量未配置，分析脚本不会加载，也不会发送统计请求。本地预览同样不启用统计。

部署反馈

部署反馈是公开 GitHub Issue。只需填写真实平台、安装结果和阻碍；不要提交域名、IP、访问令牌、密码、证书、密钥、日志中的私密地址或任何个人身份信息。

保留与删除

Pages 本身不保存访客数据库。GoatCounter 的数据保留与删除由项目所有者在对应站点设置中管理；GitHub Issue 的编辑或删除按 GitHub 平台规则处理。

联系与选择

可以通过浏览器阻止第三方脚本，或在 GitHub 创建不含私密信息的公开问题。疑似安全漏洞必须使用私密漏洞报告，不要进入部署反馈。
