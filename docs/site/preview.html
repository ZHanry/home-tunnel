范围

9.0.0 是稳定版，10.0.0 还在开发。

正式版本号不表示每一项远控能力都已验收。10.0.0 的安全桌面、音频、文件传输和稳定下载都还没有验收结果。契约仍是已发布的 api-v1.3.0；api-v1.4.0 尚未冻结。

两条路径

不要把计划中的 10.0 能力写成已经可用。
路径9.0.0 已发布行为10.0.0 计划
路径远程控制9.0.0 已发布行为同一服务器上的本机批准、固定密码、一次性密码。设备码不是接入码。载荷只走 UDP 直连。10.0.0 计划仍只走 UDP。无人值守、安全桌面、音频和双向文件都待验收。
路径FRP 发布9.0.0 已发布行为HTTP/HTTPS、TCP、UDP，由家里的 Agent 连接 FRP 0.70.1。10.0.0 计划向导和 NAS、Home Assistant、Immich、Jellyfin、SSH、RDP、RTSP 模板待验收。

9.0.0 不能忽略的限制

  • Windows 登录前、锁屏和 UAC 安全桌面控制尚未完成。
  • 音频、macOS/Wayland 被控、AV1/HEVC 未交付。
  • 剪贴板跨端互通、arm64 APK 运行、跨网、完整升级恢复和长期在线仍未验收。
  • Linux x64 X11 的证据来自隔离环境，不等于实体桌面。
  • 8.0 验收记录是历史材料，不能代替 9.0 或 10.0 的产物验证。
