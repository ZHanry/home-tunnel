范围

10.1.0 是稳定版，部分项目尚未验证。

稳定组合为 Server / Client 10.1.0 + Android 10.0.0。Android 原始文件、版本与摘要保留不变。FRP 保持 0.70.1；增量契约为 api-v1.5.0，历史契约不变。未运行项目不计为通过。详见发布说明。

10.1 更新

修复 Windows 审批弹窗底色和显示时机、阻止连接本机；原生登录通过短时单次交接复用到仅限远控的子会话。设置与更新合并，当前设备改名移到“我的设备”，登录布局、窄窗口滚动和键盘行为得到改善。登录交接与当前设备改名需要 Server 10.1.0。

两条路径

远控继续使用端到端 DTLS 加密 UDP，浏览器可用可选 UDP TURN 中继；Android 与 9.x 被控端只走直连，没有 TCP/FRP/HTTP/WSS 载荷回退。服务发布使用 FRP 0.70.1 的 HTTP/HTTPS、TCP 与 UDP 路径。

实测范围

10.1.0 的原始 Windows worker 字节在同机 Chromium 与生产源码 QA host 的隔离回环环境中通过 30 次连接、7202.463 秒活动和 1391 次采样；显式重启 QA host 后，新配对恢复输入耗时 3507.7 ms。

实测包含原生画面、可信键鼠与中文、签名配对、UDP/DTLS、会话关闭与输入释放。服务器由锁定生产源码本地构建，不代表最终容器或已部署生产环境验收。QA 账号令牌与单次授权使用 10800 秒测试有效期，生产租约和信令令牌续期逻辑未修改。

未验证项目

  • 这些结果不代表完整安装版 GUI、Windows 服务、两台独立 Windows 终端、Android、断网恢复、24 小时在线或 Linux/macOS 运行验收。
  • 完整审批、固定密码、临时密码界面流程；本轮未覆盖的音频、剪贴板、双向文件、多显示器与 DPI。
  • 完整安装器升级与备份恢复；NAT、IPv6、UDP 被封及断网恢复矩阵。
  • 最终 APK 与实体手机；账号令牌刷新、性能对比、隧道运行矩阵、完整最终界面审查。
  • 24 小时测试未运行。显式 QA host 重启不能证明自动服务重启或断网恢复。
