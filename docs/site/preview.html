Home Tunnel 9.0.0

9.0.0 分开内网穿透与远程桌面，刷新网站、Windows 和 Android 界面。正式版本号不代表完整方案或全部平台已验收；请核对各组件 Release 的实际产物与测试证据。

当前远控范围

  • Windows x64 与浏览器：独立远控窗口；临时请求并批准、固定密码、一次性临时密码三种授权；签名票据、租约和即时撤销。视频、键鼠、文本及文件的最终包结果以本版组件 Release 证据为准。
  • Linux x64 X11：仅观看、键盘和鼠标。当前证据来自隔离 Xvfb 环境，实体桌面和锁屏恢复未验收；文本、剪贴板和文件不可用。Linux arm64、NAS 和 CLI 继续提供隧道功能。
  • Android：保留多服务器管理，提供三种连接方式和远控画面。API 35 x86_64 模拟器测试不证明发行 arm64 APK 或真机运行；实际剪贴板互通仍未验收，音频与文件不可用。

远控画面、输入和文件只能走两端 UDP P2P。服务器负责身份、授权、信令和 STUN；无法直连时明确失败，不回退至 TURN、FRP、HTTP 或 WSS 载荷转发。原有隧道业务仍使用自己的公网服务端转发。

尚未交付或完成验收

Windows 锁屏、登录前和 UAC 安全桌面控制与高权限代理尚未完成。系统声音、麦克风回传、macOS/Wayland 被控、AV1/HEVC 尚未交付。剪贴板互通、真实跨网、完整升级恢复和长期在线仍待验收。

Android 被控、图片剪贴板和目录递归传输不在当前范围内。未支持的能力不应被报告为通过；模拟器、隔离环境与云端构建不能替代对应实机证据。

Windows/macOS 平台签名状态以每个实际产物报告为准。Android 沿用原 applicationId 和发行证书。网站控制台图片仍是标明版本的 7.0.0 历史示例。

9.0.0 scope and limits

Windows and browser remote access offers a host-approved request, a host-configured fixed password, and a one-use temporary password, with a separate viewer window. Final video, input and file results belong to the component Release evidence. Pre-login, locked-screen and UAC secure-desktop control remain incomplete.

Linux x64 X11 exposes viewing, keyboard and pointer only, with isolated Xvfb evidence. Android includes remote-control UI and a shared native controller, but API 35 x86_64 emulator results do not validate the arm64 APK or a physical phone. Actual clipboard interoperability remains unverified.

Audio, macOS/Wayland hosting and AV1/HEVC are not delivered. Cross-network traversal, complete upgrade/restore and long-running acceptance remain outstanding. A stable version number does not imply full-plan completion.

Remote-desktop payloads require direct UDP P2P. The server handles identity, authorization, signaling and STUN; an unavailable direct path fails with no TURN, tunnel, HTTP or WSS payload fallback. Existing tunnel services retain their server-forwarded path.
