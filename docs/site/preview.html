范围

10.0.0 是稳定版，部分项目尚未验证。

本版的验证尚未完成。下面分别列出实测范围、未验证项目和不可用功能。未运行的项目不计为通过。契约是已冻结的 api-v1.4.0。完整清单见发布说明。

两条路径

10.0.0 的行为，以及和 9.0.0 的差别。
路径10.0.09.0.0（上一版本）
路径远程控制10.0.0端到端 DTLS 加密 UDP，优先直连。浏览器控制端在直连失败时可经可选 UDP TURN 中继连接 10.0.0 被控端，中继读不到内容，没有 TCP 回退。Android 控制端和 9.x 被控端只走直连。登录即开启被控、右下角审批、分组 9 位设备 ID；接受后放行画面、键鼠、剪贴板、文件和系统声音，麦克风不自动放行。9.0.0（上一版本）本机批准、固定密码、一次性密码。载荷只走 UDP 直连，没有中继。
路径FRP 发布10.0.0HTTP/HTTPS、TCP、UDP，FRP 0.70.1，新增引导式服务发布。9.0.0（上一版本）HTTP/HTTPS、TCP、UDP，FRP 0.70.1。

实测范围

Web 控制端经从 9.0.0 升级的生产服务器控制 Windows 10.0.0 被控端，直连 UDP 和 TURN 中继都测过：画面、键鼠、中文、双向剪贴板、控制端到被控端的文件（SHA-256 校验）、系统声音、审批弹窗和临时密码。这些是同一功能代码的开发构建，没有在最终字节上重跑。

未验证项目

  • 被控端到控制端的文件传输
  • 最终构建上的固定密码模式
  • Android 控制 Windows 被控端；Windows 控制 Windows
  • 实体 arm64 手机；最终 APK 的 API 26/35 模拟器运行
  • 多显示器与 DPI
  • 9→10 安装器升级与备份恢复
  • 30 次连续连接、2 小时和 24 小时运行
  • NAT、IPv6、UDP 被封与网络恢复矩阵
  • 性能对比与隧道运行矩阵
  • Linux 与 macOS 运行
  • 最终界面的完整 Gemini 审查

不可用

  • 锁屏、登录前和 UAC 安全桌面控制。
  • 麦克风回传。
  • Windows/macOS 发行商签名；SHA-256 和 Sigstore 不是发行商签名。Android 保持原发行证书。
  • 8.0 验收记录是历史材料，不能代替 10.0 的产物验证。
