Privacy

Privacy

Project website

This site explains the product and links to downloads. It does not require sign-in and it does not collect Home Tunnel accounts or device credentials. GitHub Pages hosts the site and processes basic request information. The theme choice stays in this browser under the localStorage key home-tunnel-theme and is not sent to a Home Tunnel server.

The repository leaves page analytics empty. Only a configured GoatCounter HTTPS /count endpoint on the GitHub Pages production host loads the counter from gc.zgo.at. That counter covers visits to this website, not Home Tunnel accounts, remote-desktop pictures, or tunnel credentials. See goatcounter.com/privacy.

Self-hosted service

Accounts, devices, connections, traffic statistics, and audit records are stored on the server you deploy and are managed by that deployment's administrator. Device credentials authorize connections. Android sign-in manages your own server and is not stored on this website.

Remote-control pictures, input, and planned file or audio payloads do not pass through this website. Your server handles identity, authorization, and signaling. Direct UDP runs between the two endpoints. FRP publishes the local services you configure, and that traffic crosses your server rather than this documentation site.

Feedback

Remove passwords, tokens, private keys, enrollment codes, and personal information before opening a GitHub issue. Report security problems through private vulnerability reports, not a public issue. SECURITY.md in the repository points to the same place.
