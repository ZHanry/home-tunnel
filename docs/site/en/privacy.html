HOME TUNNEL

Privacy

Project website

This site provides product information and download links. It does not require sign-in or collect Home Tunnel accounts or device credentials. GitHub Pages hosts the site and processes basic request information.

Self-hosted service

Accounts, devices, connections, traffic statistics and audit records are stored on the server you deploy, under the control of its administrator. Device credentials authorize tunnels; Android sessions provide remote management.

Feedback and contact

Remove passwords, tokens, private keys and personal information before filing a GitHub issue. For security reports, follow SECURITY.md in the repository.
