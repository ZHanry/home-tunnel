Privacy

Small, explicit, aggregate.

This is a static GitHub Pages site. It does not connect to a Home Tunnel deployment and never receives console credentials, home-service addresses, tunnel tokens, or device configuration.

What may be measured

If the repository owner configures the public GOATCOUNTER_ENDPOINT repository variable, Pages loads GoatCounter only on zhanry.github.io. It records aggregate page views, referrers, and named clicks for Quick Start, Release, GitHub, and deployment feedback. The endpoint is omitted and analytics stays disabled when the variable is empty.

Cookies and deployment data

The Pages integration does not set a project cookie and does not add advertising or cross-site tracking. Never place a real domain, IP address, access token, password, or credential in a deployment feedback Issue. Feedback asks only for platform, installation result, and blocker.

Source and contact

The complete site and analytics loader are reviewable in the repository. For suspected security vulnerabilities, use private vulnerability reporting; do not disclose them in a public Issue.
