Before you connect.

Do I need a server and domain?

Yes. Your public Linux host runs the control plane and relay. Home hosts connect outbound and do not need a public IP.

Does Android run the tunnels?

No. Android manages them; the Agent keeps running on your home computer or NAS.

Can I mix 6.x and 7.0 clients?

The supported stack is 7.0.0 across all first-party components and the managed Agent. Upgrade together. FRP keeps its upstream version.

How can I help?
