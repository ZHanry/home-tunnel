Before you connect

Do I need my own server?

Yes. Install the Web server and sign in from each app. Service settings are retrieved after login.

Can the browser control a computer directly?

Yes. Select a Windows or Linux device or enter its ID. The host must approve the request or verify its remote password.

What happens if P2P fails?

The session ends with a clear error. There is no media relay fallback; independent FRP tunnels have their own lifecycle.

Which Android package should I use?

One universal APK includes ARM64 and x86_64. The existing application ID and release certificate are preserved for upgrades.
