Scope

10.1.0 is stable. Verification remains incomplete.

The stable combination is Server / Client 10.1.0 + Android 10.0.0. Android keeps its original files, version and hashes. FRP stays 0.70.1; the additive contract is api-v1.5.0 and historical contracts are unchanged. Tests that were not run are not counted as passed. Read the release notes.

10.1 changes

Fixes Windows approval-popup background and timing, blocks self-device connections, and reuses native sign-in through a short-lived, single-use, remote-only child session. Settings and update controls are combined, current-device rename moves to My Devices, and sign-in layout, narrow-window scrolling and keyboard behavior improve. Sign-in handoff and current-device rename require Server 10.1.0.

Two paths

Remote control retains end-to-end DTLS-encrypted UDP, with optional UDP TURN for browser viewers. Android and 9.x hosts remain direct-only. There is no TCP/FRP/HTTP/WSS payload fallback. Service publishing uses FRP 0.70.1 for HTTP/HTTPS, TCP and UDP.

Verified scope

The original 10.1.0 Windows worker bytes passed 30 connections and 7202.463 seconds of activity with 1391 samples, using same-machine Chromium and a production-source QA host in an isolated loopback environment. After an explicit QA host restart, a new pairing restored input in 3507.7 ms.

The run covers native video, trusted keyboard/pointer and Unicode, signed pairing, UDP/DTLS, session closure and input release. The server was locally built from locked production source, not verified as the final container or a deployed production system. The disposable account token and one-session grant use a 10800-second test lifetime; production lease and signaling-token renewal logic is unchanged.

Unverified items

  • This does not establish full installed-GUI, Windows service, independent Windows-endpoint, Android, network-outage recovery, 24-hour online, or Linux/macOS runtime acceptance.
  • Full approval, fixed-password and temporary-password UI flows; audio, clipboard, bidirectional files, multi-monitor and DPI not covered by this run.
  • Full installer upgrade and backup restore; NAT, IPv6, blocked UDP and network-outage recovery.
  • Final APK and physical phones; account-token refresh, performance comparisons, tunnel runtime matrix and full final-UI review.
  • The 24-hour test was not run. An explicit QA host restart does not prove automatic service restart or network recovery.

Limits and historical screenshots

Lock screen, pre-login, UAC secure desktop and microphone return are unavailable. Windows Authenticode / macOS Developer ID release signing is not configured. SHA-256 and Sigstore are not publisher signatures. Android retains its release certificate. Historical 10.0.0, 9.0.0 and 8.0 evidence does not verify final 10.1.0 bytes.
