Scope

10.0.0 is stable. Verification remains incomplete.

Verification of this release remains incomplete. This page lists what was tested, what remains unverified, and what is unavailable. Tests that were not run are not counted as passed. The contract is the frozen api-v1.4.0. The release notes have the full list.

Two paths

10.0.0 behavior and how it differs from 9.0.0.
Path10.0.09.0.0 (previous)
PathRemote control10.0.0End-to-end DTLS-encrypted UDP, direct first. When direct fails, a browser viewer can reach a 10.0.0 host through the optional UDP TURN relay, which cannot read payloads; there is no TCP fallback. Android controllers and 9.x hosts are direct-only. Hosting on after sign-in, bottom-right approval, grouped 9-digit device ID; accepting grants screen, input, clipboard, files, and system audio, and the microphone is never auto-approved.9.0.0 (previous)Local approval, a fixed password, or a one-time password. Direct UDP only, no relay.
PathFRP publishing10.0.0HTTP/HTTPS, TCP, and UDP with FRP 0.70.1, plus guided service publishing.9.0.0 (previous)HTTP/HTTPS, TCP, and UDP with FRP 0.70.1.

What was tested

A Web viewer controlled a Windows 10.0.0 host through the production server (upgraded from 9.0.0), over direct UDP and the TURN relay: screen, keyboard, mouse, Chinese text, clipboard both ways, viewer-to-host files with a SHA-256 check, system audio, the approval popup, and the temporary password. These were development builds of the same feature code, not re-run on the final bytes.

Unverified items

  • Host-to-viewer file transfer
  • Fixed-password mode on the final build
  • Android controlling a Windows host; Windows-to-Windows
  • Physical arm64 phones; API 26/35 emulator runs of the final APK
  • Multiple monitors and DPI
  • 9-to-10 installer upgrade and backup restore
  • 30-connection repeat, 2-hour and 24-hour soaks
  • NAT, IPv6, blocked-UDP, and network-recovery matrix
  • Performance comparison and the tunnel runtime matrix
  • Linux and macOS runtime
  • A full Gemini review of the final UI

Not available

  • Lock screen, pre-login, and UAC secure-desktop control.
  • Microphone return.
  • Windows/macOS publisher signatures; SHA-256 and Sigstore are not publisher signatures. Android keeps its release certificate.
  • The 8.0 acceptance record is historical. It does not verify 10.0 bytes.
