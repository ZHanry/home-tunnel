# 开始使用

1. 准备公网 Linux 主机、域名和 Docker Compose，按[服务端部署指南](https://github.com/ZHanry/home-tunnel-server/blob/main/docs/SELF_HOSTING.md)完成部署。
2. 使用初始管理员账号登录 Web 控制台，设置新密码并创建普通用户。
3. 从[下载页](DOWNLOADS.md)安装适合家庭电脑或 NAS 的客户端，用普通用户账号登录。
4. 在“本机服务”中创建连接，填写服务名称、公网子域和本地目标。确认电脑可以直接访问该目标。
5. 等待连接在线，复制公网地址，在外部网络访问服务。
6. 在 Android 的“设备”中选择电脑，或在 Web 控制台中远程管理账号名下的连接。

若无法访问，依次检查本地服务是否启动、客户端是否在线、公网服务器防火墙与 DNS 是否正确。公开敏感服务时配置访问保护。TCP / UDP 服务的认证和加密由应用提供。
