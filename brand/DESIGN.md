# 栖云桥 / NestLink

采用蓝白工作台，以本机共享、发起连接、最近连接和家庭设备为远控入口。中英文名称在 Web、桌面、Android、CLI 与下载站一致。

品牌蓝 #1967D2，页面 #F7F9FC，内容面 #FFFFFF，文字 #12233F，边线 #DCE5F3；深色界面使用同一结构与蓝色强调。中文使用系统中文字体，英文使用各平台系统界面字体。

Web 与桌面左侧导航，移动端底部导航。语言和主题入口等宽，账号与版本入口铺满侧栏。所有主要页面隐藏可见滚动条；滚轮、触控、键盘、焦点与无障碍滚动保持可用。

账号登录后自动读取自建服务配置。远控和穿透分别管理生命周期；跨账号协助仍须被控端批准或验证连接密码。空状态居中，分页统一；版本入口打开更新弹窗。

icon.svg 为原创蓝色连接节点图标，按同一源文件生成应用、窗口、托盘、安装器和发行图标。配置目录、设备身份、安装升级身份和发行证书保持既有身份。
